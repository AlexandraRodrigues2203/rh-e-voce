# RH | e Você - GitHub Pages

Arquivos prontos para publicar o ícone da engrenagem no iPhone e Android.

## Enviar ao GitHub

1. No repositório `rh-e-voce`, clique em **Adicionar arquivo > Upload files**.
2. Extraia o ZIP e envie **todos os arquivos da pasta**, sem criar outra pasta dentro do repositório.
3. Clique em **Commit changes**.
4. Abra **Settings > Pages**.
5. Em Source, escolha **Deploy from a branch**.
6. Selecione a branch principal (`main` ou `principal`) e a pasta `/(root)`.
7. Clique em **Save**.

## Configurar o endereço do Portal RH

Ao tocar pela primeira vez em **Abrir Portal RH**, cole o endereço do Apps Script publicado, começando com `https://` e terminando em `/exec`. O endereço fica salvo no celular.

Também é possível configurar automaticamente abrindo uma única vez:

`https://SEU-USUARIO.github.io/rh-e-voce/?portal=LINK_CODIFICADO_DO_PORTAL`

## Instalar no iPhone

1. Abra o endereço do GitHub Pages no Safari.
2. Toque em Compartilhar.
3. Toque em Adicionar à Tela de Início.
4. Confirme o nome RH | e Você.

O arquivo `apple-touch-icon.png` contém a engrenagem oficial.
