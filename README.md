# RH | e Você — Versão 11.0

Versão PWA com a **engrenagem oficial enviada pelo usuário** aplicada ao ícone do aplicativo.

## Publicação

1. Extraia o ZIP.
2. Envie todos os arquivos e a pasta `icons` para a raiz do repositório `rh-e-voce`.
3. Confirme o commit.
4. Aguarde o GitHub Pages publicar.
5. Teste: `https://alexandrarodrigues2203.github.io/rh-e-voce/?v=11`

## Importante no celular

- Apague o atalho/app antigo antes de instalar novamente.
- No Android, limpe os dados do site no Chrome caso o ícone antigo permaneça.
- No iPhone, remova o ícone antigo e adicione novamente pelo Safari.

## Ícones incluídos

- `apple-touch-icon.png` — 180×180
- `icons/icon-192.png` — Android/PWA
- `icons/icon-512.png` — Android/PWA
- `icons/icon-maskable-512.png` — Android adaptável
- `icons/icon-1024.png` — alta resolução
- `favicon-16x16.png` e `favicon-32x32.png`
