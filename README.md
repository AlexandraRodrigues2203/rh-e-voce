# Portal RH | e Você - Versão 12.0

Pacote para corrigir os ícones do aplicativo no iPhone e Android.

## Como publicar

1. No GitHub, envie a pasta `icons` inteira.
2. Substitua `manifest.json`, `site.webmanifest`, `service-worker.js` e `index.html`.
3. Envie também os arquivos `apple-touch-icon.png`, `favicon-16x16.png`, `favicon-32x32.png` e `favicon.png`.
4. Preserve os seus arquivos atuais `app.html`, `app.js`, `config.js` e demais arquivos do portal.
5. Aguarde a publicação do GitHub Pages.
6. No iPhone, remova o atalho antigo e adicione novamente pela opção Compartilhar > Adicionar à Tela de Início.

Importante: os nomes dos arquivos não possuem acentos e a pasta deve se chamar exatamente `icons`.
