# RH | e Você — Versão 7.0

Projeto PWA pronto para GitHub Pages.

## Publicação
1. Extraia o ZIP.
2. Envie todos os arquivos e a pasta `icons` para a raiz do repositório `rh-e-voce`.
3. Confirme o commit.
4. Aguarde a publicação do GitHub Pages.
5. Abra: https://alexandrarodrigues2203.github.io/rh-e-voce/

O link do Apps Script já está configurado em `config.js`; o usuário não precisa colar nada.
